# Image Editing App

## Project Description

The Image Editor App is a web-based application developed using Streamlit and OpenCV that allows users to upload an image and apply different image processing filters such as blur, sharpness, brightness, contrast, grayscale, and edge detection. The app displays both the original image and the processed image side-by-side for easy comparison. It also provides a download option so users can save the final edited image.

---

## Technologies Used

* Python
* Streamlit
* OpenCV
* NumPy
* Pillow

---

## Features of the Project

* Upload image files (JPG, JPEG, PNG)
* Apply multiple image filters
* View original and edited images side-by-side
* Adjust brightness, contrast, blur, and sharpness
* Use grayscale and edge detection filters
* Download the final processed image
* Simple and interactive user interface

---

## Setup Instructions

### Step 1: Clone the Repository

```bash id="setup01"

```

### Step 2: Install Required Libraries

### Step 3: Run the Application
